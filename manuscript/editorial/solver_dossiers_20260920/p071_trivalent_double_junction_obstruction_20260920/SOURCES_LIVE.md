# P07.1 trivalent double-junction obstruction: sources

Date: 2026-09-20

The proposition introduces no new external citation.  It uses only the
book-local exact CLD star coordinates and the two-star generator convention
already fixed in the immediately preceding bivalent-product theorem.

The proof is self-contained after those definitions.  Its inputs are:

1. joint convexity on each branch rectangle;
2. common smooth restrictions on both families of node axes;
3. the two exact three-branch balance laws;
4. stability of branchwise convexity under local pointwise decreasing
   limits and sheafification;
5. the one-dimensional fact that a convex function with a local minimum at
   an endpoint has that endpoint as a global minimum.

No analytic realization, ambient convex extension, endpoint trace, or
terminal-collar assertion is used.
