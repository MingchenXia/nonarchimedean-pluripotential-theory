# P07.1 trivalent double-junction obstruction audit

Date: 20 September 2026

Status: verified and integrated into the live book.  The pre-integration
comment at the head of the frozen principal statement is retained because
changing those exact verified bytes would invalidate the receipt.

## Claim boundary

The packet proves one necessary mixed Jensen condition for the full
decreasing-sequential sheaf generated by the displayed two-star smooth psh
model.  It then gives an explicit continuous piecewise-affine function that
passes both complete one-factor star--line comparison families but violates
the mixed condition.

It does **not** claim that the mixed inequalities characterize the generated
sheaf, that every function satisfying them is first-stage approachable, or
that P07.1 is retired.

## Proof-obligation ledger

1. **Generator necessity.**  The common axis germs make the corner gradient
   on rectangle `(i,j)` equal to `(alpha_i,beta_j)`.  Joint convexity gives
   the corner supporting-plane inequality.  Equal radial mass in all three
   branches cancels both balanced linear terms.
2. **Closure and shrinking domains.**  A bare locality argument would be
   invalid.  For a fixed balanced atomic configuration, scale every radius
   by `t`.  The weighted sum of the resulting branch-rectangle values is
   convex in `t`.  An inequality on any node collar makes `t=0` a local
   minimum, hence a global minimum.  This radial propagation upgrades the
   locally witnessed inequality to the whole fixed chart before a
   decreasing limit is taken.  It also repairs sheafification: use the cover
   member containing the double node at small scale, then propagate.
3. **Rectangle convexity.**  On a diagonal rectangle the formula is
   `max(-2r+s,r-2s)`; off the diagonal it is affine.
4. **Axis gluing.**  Every rectangle restricts to `r` on `s=0` and to `s`
   on `r=0`.
5. **First separate family.**  The negative term occurs only on branch
   `i=j` and is bounded below by minus three times that branch's radial
   mass, exactly cancelling the total radial mass `3M`.
6. **Second separate family.**  This is the symmetric calculation.
7. **Mixed violation.**  The three equally weighted diagonal atoms have
   both balanced marginals and average value `-rho`, below the double-node
   value zero.

## Exceptional cases

- Zero radial moment is allowed; then all corresponding radii vanish and
  the same calculation applies.
- Atoms of zero weight can be deleted, so the statement uses positive
  weights without loss.
- All arguments are local on bounded node collars; no full endpoint or
  terminal-collar assertion is made.
- The hierarchy argument uses the star-shaped product node chart.  It does
  not claim the same propagation on an arbitrary non-star-shaped open set;
  one first restricts to such a chart around the double node.
- The branch labels are deliberately synchronized only to exhibit the
  minimal trivalent obstruction.  No claim for unequal finite valences is
  needed.
