# P06.2 polyannulus coefficient monodromy v63: source ledger

- `lem:ch15-log-smooth`: the logarithmic absolute value of an analytic unit
  is smooth and has zero mixed current.
- `thm:p062-open-polyannulus-products-over-curves`: unique base and slope
  coefficients for a continuous zero-current function in every standard
  strict polyannulus product chart; base coefficients have zero current and
  slopes are locally constant.
- `cor:p062-open-polyannulus-bundles-over-curves`: the locally trivial
  bundle geometry and the already integrated chartwise regularity result.

No new external theorem is used.  Matrix invertibility, the Cech cocycle
law, atlas independence, and the dual slope transformation are formal
consequences of the uniqueness statement in the product theorem.
