# P02.2 invariant split-toric locally Fubini--Study regularization — source ledger

Status: source-scoped positive companion result.  It applies only to finite
continuous maximal-compact-torus-invariant current-psh functions on an
ordinary open set compactly contained in one ordinary open convex tropical chamber of a split
torus.  It does not identify arbitrary classically psh functions with this
class and does not retire P02.2.

## Claim-to-source map

| Step | Source / direct argument | Scope control |
| --- | --- | --- |
| Invariant psh potential is finite convex tropical data | Burgos Gil--Gubler--Jell--Künnemann, Theorem 5.3.11 | The maximal-compact-torus invariance, finiteness, dense torus, and trivial toric line-bundle specialization are essential. |
| Strictly decreasing smooth convex functions | The book proposition on radial mollification | The target closure is compactly contained in the convex chamber; the added positive constants create a quantitative interstage gap. |
| Finite supporting-plane maxima | Elementary compactness for the tangent-plane formula for smooth convex functions | It is used only on the fixed compact target closure. |
| Rational-lattice affine majorants | Direct rounding argument using a nonzero element of the value group | One common denominator is selected for each finite maximum; no density assumption on the value group is made. |
| The maxima are locally Fubini--Study | Gubler--Jell--Rabinoff, Definition 7.8 and Section 7.9 | Each displayed term is a positive real multiple of a finite maximum of negative logarithms of invertible analytic torus characters. |

## Deliberate boundaries

1. The construction stays on one fixed relatively compact ordinary open set because the torus
   characters used in every finite maximum are invertible on the entire
   split torus.
2. It does not invoke the local semipositive-real-PL-to-LFS theorem once for
   each member of a sequence, so it does not hide a countable
   common-neighbourhood assertion.
3. It supplies neither an approximation for arbitrary noninvariant psh
   functions nor an assertion on a toric boundary stratum or a nonconvex
   ambient tropical chamber.
