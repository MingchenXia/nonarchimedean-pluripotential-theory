# Higher-bidegree relative-polar research preservation

This wrapper preserves the nine owned files of the frozen higher-bidegree relative-polar research dossier byte-for-byte. The original read-only checker is run before copying. The argument retains integer a>=4, arbitrary positive closed base currents, and the explicit trace-integrability hypothesis for the auxiliary pole.

The dossier contains a candidate relative-pole estimate and removal criterion, a given-Cartier-flag approximation argument, an abstract tropical obstruction to trace/energy-only reasoning, and an actual analytic zero-mass but logarithmically nonintegrable example. It does not solve the general P21.3 problem. Its internal arithmetic and bidegree checks are not independent mathematical or production verification.

Root read the complete main argument before preservation and reran its mechanical checker. Further independent mathematical and correctly authorized production reviews remain required. This does not authorize any live-book theorem or retirement.

Existing target directories are refused. PRESERVATION.json records original paths, repository paths, bytes and SHA256 values. The NUL list selects only this wrapper and the preserved dossier. The --verify mode is read-only and checks exact archived bytes and directory membership. Original frozen dependency pointers are retained; their relocation or permanent availability is not falsely promised. No service, production memory, existing frozen input or live chapter is modified.
