a good separated boundaryless rig-smooth strictly $K$-analytic space, and
let $h:X\to\mathbf R$ be a real-valued $\mathbf R$-PL function.  If
\[

\]

Consequently, on this class of spaces, an $\mathbf R$-PL function is model
semipositive if and only if its Chambert--Loir--Ducros current is positive.
\end{theorem}
