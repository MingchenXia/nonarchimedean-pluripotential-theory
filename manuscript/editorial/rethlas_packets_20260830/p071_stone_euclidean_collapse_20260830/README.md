# Isolated P07.1 candidate packet

This directory freezes a candidate first-stage-collapse theorem for the
exact product of:

- a locally compact Hausdorff clopen-base parameter space carrying the
  locally constant affine G-tropical structure; and
- an open convex Euclidean domain with its standard affine structure.

Files:

- statement.tex: exact scoped statement;
- proof.tex: source-aware proof;
- SOURCE_AND_OBLIGATION_MATRIX.md: source legality and proof obligations;
- HOSTILE_BOUNDARY_AUDIT.md: fail-closed scope audit;
- SHA256SUMS: exact-byte fingerprints, generated after the freeze.

The main mechanism is a countable Boolean quotient of the parameter space,
followed by nested clopen upper envelopes, Euclidean mollification, and
summable tail corrections. It yields one decreasing sequence of smooth psh
functions on a fixed product neighbourhood.

No live manuscript file was edited. Production Rethlas verification is
pending. This packet is not sufficient to retire P07.1 and makes no claim
of novelty or priority.
