# P06.2 annulus endpoint-only dossier

This directory is separate from all v1/v2/v3 theorem packets and from the
live manuscript.

- `ENDPOINT_ONLY_DOSSIER.md` gives a fail-closed proof candidate for strict
  half-closed and closed annuli over an arbitrary complete non-Archimedean
  field.
- `REFERENCE_LEDGER.md` records exact source scope and locators.

Main conclusion of the research pass: the one-dimensional endpoint defect can
be repaired by polynomial tubes and finite-flat trace on each endpoint virtual
disc branch.  The full product extension has a precise route but remains
quarantined pending independent audit of generalized local slicing and
multi-endpoint fibre-product limits.

No Rethlas call was made, no live-book file was changed, and the v3 strict-open
packet was not modified.
