\emph{\(P\) is the global envelope.}
Let \(\varphi\in\PSH(X,\theta)\) satisfy \(\varphi\leq u\).
By \cref{lem:ch23-psh-vertex-chord}, its vertex chord
\(A\varphi\) is an admissible real model function on
\(\mathcal X\).  Its vertex vector therefore belongs to the same
polyhedron \(K\) used above.  The already proved inequalities for
every vector in \(K\) give
\[
            \varphi\leq A\varphi\leq P\circ p_{\mathcal X}
            \qquad\text{on }X^{\An}.
\]
Conversely the computed \(P\circ p_{\mathcal X}\) is itself a
\(\theta\)-psh model competitor below \(u\).  Taking the supremum
over all \(\varphi\) proves equality with \(P_\theta(u)\) on the
whole analytification, not only at its vertices.  The argument uses
the real-model chord lemma in the BFJ regime; it does not apply a
rational-model slope criterion to an arbitrary singular psh function.
