\begin{theorem}
\label{thm:ch30-finite-bounded-projection}
Let \(f:Y\to X\) be finite surjective of degree \(d\) between smooth
projective \(K\)-varieties of dimension \(n\), and let
\(\varphi_1,\ldots,\varphi_n\) be bounded \(\theta\)-psh functions on
\(X\).  Then \(f^*\varphi_1,\ldots,f^*\varphi_n\) are bounded
\(f^*\theta\)-psh functions on \(Y\) and
\begin{equation}
\label{eq:ch30-bounded-projection}
 f_*\MA_{f^*\theta}(f^*\varphi_1,\ldots,f^*\varphi_n)
 =d\,\MA_\theta(\varphi_1,\ldots,\varphi_n).
\end{equation}
\end{theorem}

\begin{proof}
Boundedness of \(f^*\varphi_i\) is clear, and psh-ness is
\Cref{prop:finite-pullback-psh}.  By
\Cref{thm:bfj-decreasing-regularization}, for each \(i\) choose a
decreasing net \(\varphi_i^{\alpha_i}\searrow\varphi_i\) of
\(\theta\)-psh model functions, indexed by a directed set \(A_i\).
Every approximant already satisfies
\(\varphi_i^{\alpha_i}\geq\varphi_i\geq\inf_{X^{\An}}\varphi_i\).
For the upper bound set \(B_i=\sup_{X^{\An}}\varphi_i+1\).
The open sets \(\{\varphi_i^{\alpha_i}<B_i\}\) cover the compact space
\(X^{\An}\), because the approximants are continuous and decrease
pointwise to \(\varphi_i<B_i\).  Choose a finite subcover and then a
common upper bound \(\alpha_{i,0}\) for its indices.  On the cofinal tail
\(A_i'=\{\alpha_i:\alpha_i\geq\alpha_{i,0}\}\), decreasingness gives
\[
 \inf_{X^{\An}}\varphi_i\leq\varphi_i\leq
 \varphi_i^{\alpha_i}<B_i
 \quad\text{everywhere on }X^{\An}.
\]
Thus each tail is uniformly bounded without any maximum or minimum
operation.  Put \(A=A_1'\times\cdots\times A_n'\), ordered
componentwise, and for \(\alpha=(\alpha_1,\ldots,\alpha_n)\) write
\(\varphi_i^\alpha=\varphi_i^{\alpha_i}\).
These are decreasing nets with their original limits.  Since the number
of slots is finite, one bound works for all of them and for their
pullbacks.  By \Cref{lem:ch30-pullback-model-calculus}\,
\cref{itm:ch30-pbm:divisor,itm:ch30-pbm:ddc}, the pullbacks are still
psh model functions and decrease to \(f^*\varphi_i\).

Set
\[
 \begin{aligned}
 \mu_\alpha^Y
   &:=\MA_{f^*\theta}(f^*\varphi_1^\alpha,\ldots,
      f^*\varphi_n^\alpha),&
 \mu^Y
   &:=\MA_{f^*\theta}(f^*\varphi_1,\ldots,f^*\varphi_n),\\
 \mu_\alpha^X
   &:=\MA_\theta(\varphi_1^\alpha,\ldots,\varphi_n^\alpha),&
 \mu^X
   &:=\MA_\theta(\varphi_1,\ldots,\varphi_n).
 \end{aligned}
\]
The bounded decreasing-net continuity established in
\Cref{thm:bounded-ma-extension}, in particular Step~6 of its proof,
gives \(\mu_\alpha^X\to\mu^X\) and \(\mu_\alpha^Y\to\mu^Y\) weakly.
The model projection formula \eqref{eq:ch30-finite-test} gives
\(f_*\mu_\alpha^Y=d\mu_\alpha^X\) for every \(\alpha\).
Pushforward is weakly continuous by
\Cref{lem:ch30-pushforward-basic}\,\cref{itm:ch30-pf:weak}.
Explicitly, for every \(h\in C^0(X^{\An})\), the function
\(h\circ f^{\An}\) is continuous on \(Y^{\An}\), and hence
\[
 \begin{aligned}
 \int_{Y^{\An}}(h\circ f^{\An})\,\rd\mu^Y
 &=\lim_\alpha\int_{Y^{\An}}(h\circ f^{\An})\,\rd\mu_\alpha^Y\\
 &=d\lim_\alpha\int_{X^{\An}}h\,\rd\mu_\alpha^X
  =d\int_{X^{\An}}h\,\rd\mu^X.
 \end{aligned}
\]
Equality against all continuous test functions proves
\eqref{eq:ch30-bounded-projection}.
\end{proof}

\begin{remark}[Why the test function must be pulled back]
\label{rem:ch30-test-function}
Pushforward of a measure is tested against a continuous function \(h\)
downstairs by integrating \(h\circ f^{\An}\) upstairs.  The proof above
uses weak convergence of measures, so neither test function needs to be
psh or a model function.  The weighted statement
\eqref{eq:weighted-monotone-ma} has a narrower direct test class: its
weights are bounded psh functions.  In Step~6 of
\Cref{thm:bounded-ma-extension}, weak convergence is deduced from that
statement by linearity on the span of psh model tests and then uniform
density.  This does not assert that every continuous function is a
difference of two continuous psh functions.  Here we use the resulting
weak convergence, and only measures, not test functions, are pushed
forward.
\end{remark}
