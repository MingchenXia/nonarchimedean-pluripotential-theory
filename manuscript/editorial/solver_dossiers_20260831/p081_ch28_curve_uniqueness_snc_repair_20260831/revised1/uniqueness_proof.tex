\begin{proof}
We retain the original BFJ hypotheses of \eqref{eq:ch28-standing}.
In particular the reference form is real and its generic class is ample;
no geometric-connectedness or reduced-model hypothesis is added.
Set \(u=\varphi-\psi\), a continuous function on \(X^{\An}\).

\emph{Testing the measure equality.}
For every real model function \(h\),
\begin{equation}
\label{eq:ch28-curve-uniqueness-model-test}
 \int_{X^{\An}}u\,\ddc h=0.
\end{equation}
Indeed, \cref{prop:ch24-continuous-uniform} supplies real
\(\omega\)-psh model functions \(\varphi_j,\psi_j\) converging
uniformly to \(\varphi,\psi\), respectively, whose measures converge
weakly.  Model integration by parts, \cref{prop:model-integration-by-parts},
gives
\[
 \int h\,\rd\bigl(\MA_\omega(\varphi_j)-\MA_\omega(\psi_j)\bigr)
       =\int(\varphi_j-\psi_j)\,\ddc h.
\]
Here \(\ddc h\) is a fixed finite signed model measure.  The right-hand
side converges by uniform convergence, and the left-hand side tends to
zero by the asserted equality of the limiting measures and the continuity
of \(h\).  This proves \eqref{eq:ch28-curve-uniqueness-model-test}.

\emph{All component values on one SNC model coincide.}
Let \(\mathcal X\) be any SNC model determining \(\omega\), and write
\(\mathcal X_s=\sum_i b_iE_i\).  Its components need not have
multiplicity one.  Put
\[
 U_i=u(x_{E_i}),\qquad D_U=\sum_i b_iU_iE_i.
\]
Since \(\mathcal X\) is regular, \(D_U\) is a vertical real Cartier
divisor.  Its real model function \(h=\varphi_{D_U}\) takes the values
\(U_i\), by \cref{lem:model-function-affine} and real linearity.
The model-measure formula \eqref{eq:model-mixed-measure} and
\eqref{eq:ch28-curve-uniqueness-model-test} therefore imply
\[
 0=\sum_i b_iU_i(D_U\cdot E_i)=(D_U^2).
\]
The row-sum relation \((\mathcal X_s\cdot E_i)=0\) expands this as
\[
 0=-(D_U^2)
   =\sum_{i<j}b_ib_j(E_i\cdot E_j)(U_i-U_j)^2;
\]
this is \eqref{eq:ch20-hodge-laplacian} in dimension one.
All summands are nonnegative.  Intersection degrees are taken over the
residue field, so a nonrational intersection point contributes its full
positive residue degree.

The special fibre is connected, hence its component-incidence graph is
connected.  To recall the connectedness argument used in
\cref{thm:ch20-ddc-exact}, properness makes
\(H^0(\mathcal X,\mathcal O_{\mathcal X})\) a finite complete
\(R\)-algebra.  If the special fibre were disconnected, its decomposition
would give compatible nontrivial idempotents on all infinitesimal
thickenings, and formal functions would give a nontrivial idempotent in
this algebra.  This is impossible because it injects into
\(H^0(X,\mathcal O_X)\), a field: \(X\) is smooth and connected,
hence integral and proper.  Thus \(U_i=U_j\) along each edge forces all
\(U_i\) to equal one number \(c_{\mathcal X}\).  If there is only one
component, the conclusion is immediate.

\emph{Passing from divisorial points to the analytic curve.}
The SNC models determining \(\omega\) form a cofinal directed system
by \cref{prop:snc-cofinal}.  A dominating model retains the normalized
divisorial valuation of each old component on its strict transform.
Consequently its constant agrees with \(c_{\mathcal X}\), and common
domination shows that all these constants are one number \(c\).
Every divisorial point occurs on such a model, after common domination
and SNC resolution.  These points are dense by
\cref{rem:quasimonomial-vs-divisorial}: rational points are dense on each
skeleton and become vertices after subdivision, while the union of the
SNC skeleta is dense by \cref{thm:skeleton-inverse-limit}.
Since \(u\) is continuous, equality \(u=c\) on this dense set implies
\(u=c\) on all of \(X^{\An}\).

The argument uses SNC models with their actual multiplicities, not a
cofinal family of reduced semistable models over the original field.
It does not need a retraction formula for Monge--Amp\`ere measures.
The uses of \cref{chap:skeleta} in this last step do not impose that
chapter's extra geometric-connectedness convention.  The construction
of common SNC dominations in \cref{prop:snc-cofinal} uses only a
smooth generic fibre and the stated characteristic-zero resolution
input.  The density statements in the smooth \emph{connected} scope
are precisely \cite[\S2.4, Corollaries~2.4, 3.2 and 3.17]{BFJ16}.
Thus ordinary connectedness, already used in the component calculation,
is sufficient here.
\end{proof}
