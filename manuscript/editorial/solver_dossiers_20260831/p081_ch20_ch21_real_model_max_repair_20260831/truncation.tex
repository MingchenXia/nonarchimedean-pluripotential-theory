\begin{corollary}
\label{cor:ch20-truncation}
Let \(\theta\) be semipositive.  Every real constant is a real
\(\theta\)-psh model function.  If \(\varphi\) is a rational
\(\theta\)-psh model function and \(c\in\mathbf Q\), then
\(\max\{\varphi,c\}\) is a rational \(\theta\)-psh model function.
If in addition \(\{\theta\}\) is ample, the truncation of a real
\(\theta\)-psh model function at an arbitrary real constant is a uniform
limit of rational \(\theta\)-psh model functions, but is not necessarily
a model function.
\end{corollary}

\begin{proof}
Constants have zero model differential by
\eqref{eq:ch20-ddc-constant}.  Rational truncation follows from
\Cref{prop:ch20-model-max}, and the uniform approximation assertion is
\Cref{cor:ch20-real-max-uniform-approximation}, applied to the function
and the constant.  The example in
\Cref{ex:ch20-real-max-irrational-breakpoint} shows why the final
qualification is necessary.
\end{proof}
