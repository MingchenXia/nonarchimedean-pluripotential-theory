production receipt, atom retirement, or novelty claim.

require constructing a non-nef fixed-class MP cone. Every pseudoeffective
DXZ object embeds into a sufficiently large Kähler background with exactly
the same raw ideal function. Consequently the global DXZ quasi-psh space

normalized measures or energies.
