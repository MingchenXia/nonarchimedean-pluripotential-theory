# Source typing and scope

The candidate uses the cohomological class inclusions, their raw-ideal
compatibility, the source's divisorial operation formulas, and the separately
audited comparison inputs. The two first-named sources are primary texts:

- Xia, [Operations v3](https://arxiv.org/html/2312.17150v3), Section 3.2,
  Definition 3.5, Lemma 3.7, formula (3.5), and Section 4. These provide the
  prime-curve inverse system, its compatibility with the positive-mass
  presentation, class inclusions, and the ordered quasi-psh direct limit.
  Section 4 explicitly returns to compact Kähler spaces; projective-only
  scope of the preceding comparison section is not imported.
- MP [v2](https://arxiv.org/html/2409.06221v2), Section 4.1,
  Definition 4.3.1, and Theorem 4.3.8: model relative nefness, decreasing
  completion, and comparison of a psh function against any usc function.

The full Kähler comparison, raw USC and dominated density are new conditional
candidate inputs, not attributed to these primary sources. The present proof
does not independently verify every imported source theorem.

For operations, the precise source results used are Proposition 4.4,
Corollary 4.8, Definition 4.9, Lemma 4.10, Definition 4.14 and Lemma 4.17
of Xia Operations. They give the output class, divisorial values, and finite
endpoint formulas. Existence of the output is part of the imported DXZ
operation theory; the new assertion concerns every semivaluation.

There is a type inconsistency in the displayed component formula of source
Definition 4.16: it repeats the same background on both summands instead of
showing the two input classes and their perturbations. We do not use that
literal display. The type-correct construction at total form
theta+theta'+eta adds the components at theta+eta/2 and theta'+eta/2,
using the preceding positive-curve addition, or uses any two positive
perturbations summing to eta. The statement of Lemma 4.17 gives the class
sum and numerical formulas needed here. No source typo is silently promoted
to a formula in the candidate.

The raw class-inclusion identity is not deduced from mere equality on dense
divisorial points. It uses the identical multiplier ideals and endpoint in
the transition components. Conversely, passing from an operation's divisorial
formula to its all-point formula uses the explicit usc-antitone comparison,
with the output psh in a larger Kähler background. This order of arguments
avoids assuming the desired same-class positivity in a non-nef background.

The examples and exclusions concern function values only. They provide no
mass normalization, no fixed non-nef model approximation, no general envelope
continuity, and no independent priority claim.
