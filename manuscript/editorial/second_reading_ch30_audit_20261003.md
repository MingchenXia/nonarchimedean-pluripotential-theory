## Model and analytic interfaces

The standing reference change makes zero potentials legitimate and
records the energy cocycle. Pullback preserves semipositivity when the
original form is semipositive; bigness of the pulled-back ample class
requires a dominant generically finite map of equal dimension.

Real model functions are closed under real linear combinations, but their
maxima need not be model functions. The rational maximum statement is
retained with the Chapter 20 counterexample. The finite-model construction
uses a graph closure rather than the undefined product of a model with

index sets. Weighted convergence first tests rational model functions using
the actual psh-difference lemma; arbitrary continuous functions are reached

normalized ground fields; all trivially valued proper-support points, as
well as the zero-support trivial valuation, are fixed downstairs.

The model dictionary first chooses a common equivariant graph model.
General configurations give PL weights; only the suitable semiample ones
give Fubini--Study weights. Local Cartier multiples supply the weight
