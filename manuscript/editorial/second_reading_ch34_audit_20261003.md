## Positivity and approximation

integral curve in any base fibre. Real PL uses the tensor extension of the
rational vertical-divisor dictionary. The reverse rational scaling argument

Varying-class FS approximation is constructed using an auxiliary relatively
ample polarization, then rational approximation inside the open ample cone.
For a fixed real ample class omega, the corrected approximation uses
omega+(1-epsilon)D+epsilon H=(1-epsilon)(omega+D)+epsilon(omega+H).
