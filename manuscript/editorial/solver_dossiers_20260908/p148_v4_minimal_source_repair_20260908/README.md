# P14.8 v4 minimal-source repair

## Purpose

P14.8 v3 repaired the Cantor initial index, but its model-backed review was
strictly rejected because the attached broad Chapter 51 dependency contained
five false supporting claims and two gaps. The verifier separately found the
terminal P14.8 theorem viable when the standard envelope, multiplier-ideal,
and nonpluripolar-product facts are used correctly.

This v4 packet leaves the theorem unchanged. It replaces the broad dependency
with the small set of primary-source interfaces actually used by the proof and
supplies the omitted sequential generic-Lelong argument directly. It does not
modify the live Chapter 51 source, the v3 Cantor repair, or Chapter 72.

## Source boundary

The review attaches only the exact local copies of Boucksom's *Singularities
of plurisubharmonic functions and multiplier ideals* and BEGZ's *Monge--Ampère
equations in big cohomology classes*, identified in
`VERIFICATION_SOURCE_PACKAGE.md`. It deliberately does not attach the v3
Chapter 51 dependency that caused the rejection.

## Boundary

This is a candidate review packet, not a verification result, production
release, live integration, or evidence for retiring P14.8.
