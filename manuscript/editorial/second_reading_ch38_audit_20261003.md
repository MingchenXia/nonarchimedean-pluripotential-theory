## Numerical hypotheses and a corrected false trace assertion

The exceptional-part assertion now requires the Weil trace B_X to be
R-Cartier, so its pullback closure and numerical class are defined.
Nefness of the total class implies nonnegative degree of the trace class
on curves outside the non-isomorphism image. This proves trace nefness on
a surface, where that image is finite, but not on curves lying in a
higher-dimensional exceptional centre. The original unrestricted claim
was false, and its strict-transform argument did not cover such curves.

The added counterexample is explicit: blow up P3 at two points, let C be
the strict transform of their joining line, and set theta=H-E1-E2.
Its degree on C is -1. The pencil of planes through that line has residual
base ideal I_C after removing E1+E2. Blowing up C resolves the pencil,
making pi*theta-T globally generated, hence nef. The b-divisor -T has
trace zero, although theta+[B_X] is not nef. This computation repairs
the chapter's overbroad claim; it is not a new research/open-problem result.
The main realization proof only uses determination independence,
so it does not depend on the removed trace assertion.

No unrestricted numerical pushforward to N1 of a normal target is used.
The trace equality is an equality of Weil divisors for a chosen Cartier
representative. Pullback injectivity uses a dominating curve obtained by
cutting a component over each base curve, including exceptional centres.
Coefficientwise order is distinguished from the nef order.
