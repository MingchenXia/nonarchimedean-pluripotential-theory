# P03.1 nodal-product envelope obstruction

Status: quarantined research candidate; not production verified and not
integrated into the live book.

The candidate propagates the already production-verified nodal-curve
obstruction through a smooth strict polydisc factor.  It only claims failure
of the classical-psh and CLD-v2 conclusions.  It does not claim a formula for
the raw envelope away from the rigid zero section and makes no continuity
claim for the higher-dimensional regularized envelope.

The intended verification dependencies are:

1. the exact statement and proof of
   `prop:ch15-nodal-local-envelope`;
2. analytic pullback stability for locally Fubini--Study, real-PL,
   semipositive, and classical-psh functions;
3. the affinoid maximum principle and singleton Shilov boundary of a strict
   closed disc;
4. CLD-v2 psh implies classical psh.

No live manuscript file is modified by this dossier.
