# P06.2 arbitrary-radius residual: boundary resonance

This dossier gives a fail-closed answer to the proposed extension from
strict endpoint polycylinders to products with arbitrary positive radii.
The extension is false when the Hessian-current equation is imposed only
on the absolute analytic interior.

The counterexample is already a product of two closed discs.  If
`R` is not in the divisible closure of the value group, the reciprocal
radius pair `(R,R^{-1})` supports the relatively open tube

```text
|T S - 1| < 1.
```

Every point of this tube maps to the nonrigid endpoint Gauss point in each
coordinate, and the tube is disjoint from the absolute analytic interior.
A continuous cutoff supported in the tube is therefore invisible to the
current equation on the interior.

The dossier also records the exact repaired statement: the strict theorem
does descend if the pullback current equation holds after one complete
extension making all radii strict.  The missing implication is ascent of
the current equation from the base interior to the generally larger
interior after scalar extension; Berkovich's interior theorem gives only
the inclusion in that direction, not equality.
