# Research findings and rejected routes

The newly reconstructed finite-PC-cone lemma works on a fixed finite embedded
rational complex. Active constraints describe each tangent cone at every
relative-interior centre, including lineality and lower-dimensional faces.
Necessity uses only rational endpoints in an actual PCC. Sufficiency first
proves convexity on each contained segment, then groups arbitrary initial
directions to prove every PCC across all permitted coface structures. This is
not an envelope regularity theorem on an arbitrary balanced carrier.

A small rational box inside the minimal cone face gives an exact convex
decomposition of each prescribed real reference; every component retains all
strict recession slopes. Positive growth is a finite set of strict rational
linear tests in the coefficient space. The box is not a density argument.

The direct maximum with the original real reference is rejected. For example,
on a ray with rho=t and H=t, gamma=(3-sqrt(2))*rho and the comparison with
3+H/7 has wall t=3/(3-sqrt(2)-1/7), which is irrational. Finiteness of the real
affine maximum does not make that wall rational. The positive sum route uses
only max(rational gamma_j, rational epsilon_j H+C_j) and common rational
refinements, avoiding all new comparisons with real gamma.

The earlier rational-reference result and real cylinder argument are rebuilt
as supporting mathematics. The source intersection lemma's external AR10
premise is not invoked: primitive normals, balancing, refinement, locality and
mixed commutativity are proved directly in dimension two. PC implies every
ordinary-open PAPC local real-cycle test by rational endpoint PCCs and rational
generation of the nonnegative balancing cone.

The global negative envelope argument uses only upper growth for raw competitors.
An original-product diagonal PCC fixes the chosen junction value; all other
function-structure vertices have zero bump. Far rational recession endpoints
prove domination at every real point. This avoids a nodal relaxation, a local
gluing theorem, or a two-sided assumption on raw competitors.

The integral is complete: all original vertices and all obstacle refinement
vertices are addressed, with zero second coefficient for newly inserted
vertices. P+1/n has exactly the PA measures, so no infinity term is introduced.

There is no identified gap in the new all-real-reference theorem within the
stated two-graph subclass after this author audit. This is an unverified proof
draft, not an independent certificate. Original P05.2 remains open for
arbitrary balanced spaces, additional product factors and the catalogue's
intrinsic smoothness/strict-positivity package. No P06.2 result is used or claimed.

No exposed operator-supervised heavy-compute service was available; no heavy
computation was necessary or launched. All execution is small standard-library
arithmetic, source snapshots and ordinary document compilation. No alternate
model, subagent, network, external message, install, authorization change,
proxy/CA change, SQL mutation or old-artifact write was used.
