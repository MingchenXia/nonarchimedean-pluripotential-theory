# Research report

Date: 13 September 2026

## Result

The first-stage collapse is proved for the product of an arbitrary locally
compact Hausdorff clopen-base parameter, carrying only locally constant
affine functions, with the exact CLD star X_B for an arbitrary nonempty
branch set B.

The explicit comparison class consists of upper-semicontinuous families of
exact-star comparison functions which factor through a compact metrizable
zero-dimensional quotient of the Stone parameter.  At the node, the family
must have one common countable set of nonconstant full branches.  This
condition is both sufficient and forced by sequential generation.

## Proof mechanism

The proof first constructs a common countable Boolean quotient for every
decreasing sequence and a common countable branch set.  For the reverse
inclusion, it regularizes only in the compact quotient variable, discretizes
that variable by nested finite clopen partitions, and takes compact
fibrewise maxima.  A uniform endpoint-trace lemma makes those maxima legal on
full branches.  It then truncates the common countable activity set to finite
sets, uses the exact-star slope budget, and applies finite harmonic smoothing
with a strict summable error gap.

## Scope

This is a genuine infinite-star product theorem, but only for the exact
cofinite-branch CLD topology and a locally constant Stone direction.  It does
not treat non-CLD infinite stars, nonconstant affine directions on the Stone
factor, an additional active convex-polyhedral factor, or nonambient
branched smooth structures.  P07.1 is therefore narrowed and remains open.
