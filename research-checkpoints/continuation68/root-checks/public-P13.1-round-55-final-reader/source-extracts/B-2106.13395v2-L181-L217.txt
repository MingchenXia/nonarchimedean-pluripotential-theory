2.1. Polarized affine varieties and test configurations. We work over an algebraically
closed field K of characteristic 0. Let X = Spec R be an n-dimensional normal affine va-
riety(not necessarily irreducible).
   Let T be a split torus acting on X. Set N := Hom(Gm , T) to be the co-weight lattice,
and let M be the dual lattice. We then have a weight decomposition on R:
                                            M
                                        R=     Rα ,
                                                α∈Λ
where Λ := {α ∈ M : Rα 6= 0}. A T action on X is good if has a unique fixed point 0 ∈ X
that is in the closure of all T-orbits and R0 = K. In this paper, we will always assume
that the action is good.
  We now set up some definitions introduced in [CS19].
Definition 2.1. The Reeb cone of X with respect to the T action is
                    C := {ξ ∈ NR := N ⊗ R : hξ, αi > 0, ∀α ∈ Λ \ {0}}
A vector ξ ∈ C is called a Reeb vector field.

Definition 2.2. A polarized affine variety is a triple (X, T, ξ) such that T is a good action
on X, and ξ is a Reeb vector field. Further, we call a polarized affine variety (X, T, ξ)
quasi-regular if ξ is rational, i.e., ξ ∈ NQ . Otherwise, it’s said to be irregular.
Remark 2.3. This is more commonly known as a log Fano cone singularity when X
has klt singularities. We adopt a different name here since we do not assume X has klt
singularities.

Definition 2.5. A (real) semivaluation v on X is a map v : R → R ∪ {∞} such that
   (1) v(f + g) ≥ min{v(f ), v(g)}, ∀f, g ∈ R;
   (2) v(f g) = v(f ) + v(g), ∀f, g ∈ R;
   (3) v(0) = ∞;
   (4) v|K∗ = 0.
A valuation v is a semivaluation such that v(f ) = ∞ if and only if f = 0.
