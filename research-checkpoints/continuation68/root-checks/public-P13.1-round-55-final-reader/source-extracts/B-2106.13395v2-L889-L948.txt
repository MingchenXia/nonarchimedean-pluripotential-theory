5.1. Fubini-Study functions.
Definition 5.1. A Fubini-Study function on X an is a function of the form

                                       log |fj | + λj
                           ϕ = max {                  : fj ∈ Rαj }
                                 1≤j≤N    hαj , ξi
       T
  where N i=1 {fi = 0} = {0}, and λj ∈ R.
  We will denote by FS(ξ) the set of Fubini-Study functions on X an with polarization ξ.
Remark 5.2. It’s worth noting that FS(ξ) behaves differently from its analog in the global
situation(see [BJ21, Proposition 2.9]). For example, when ξ is irrational, given ϕ, ψ ∈
FS(ξ), ϕ + ψ is no longer Fubini-Study. It also makes no sense to add ϕ ∈ FS(ξ) and
ψ ∈ FS(ξ ′ ) for ξ, ξ ′ linearly independent.
