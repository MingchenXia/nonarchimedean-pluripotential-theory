Definition 6.1. Two test configurations (X1 , L1 ), (X2 , L2 ) for (X, L) are equivalent if there
exists a test configuration (X3 , L3 ) that is a pull-back of both (X1 , L1 ) and (X2 , L2 ). An
equivalence class is called a non-Archimedean metric on L, and is denoted by φ. We denote
by φtriv the equivalence class of (XA1 , LA1 ).
   A non-Archimedean metric φ on the trivial line bundle OX can be viewed as a function
φ : X div → Q on the set of divisorial valuations on X. Indeed, by Theorem 4.6, every divisorial
valuation on X is of the form vE = b−1   E r(ordE ), where E is an irreducible component of X0
for some normal test configuration X of X. We may assume φ is represented by OX (D) for
some Q-Cartier divisor D supported on X0 , and then φ(vE ) = b−1   E ordE (D). When D = X0 ,
we get the constant function φ ≡ 1. In general, there exists C > 0 such that D ± CX0 is
effective; hence |φ| ≤ C, so φ is a bounded function. To the trivial metric on OX corresponds
the zero function.
