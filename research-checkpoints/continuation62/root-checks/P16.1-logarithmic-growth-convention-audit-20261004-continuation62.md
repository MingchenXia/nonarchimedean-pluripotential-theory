# Literal growth-convention check for Lyuhui Wu v1

This is a cold root source audit, not sent to the active P13 reviews or
used as a dependency of the completed P16.1 candidate. It is not a
refutation of the intended envelope theorem.

The actual source arXiv:2609.27610v1 has the following mismatch.
Definition 3.15(2), LF766–768, requires an affine FS function h with
`h <= u+O(1)` for a psh function u to have logarithmic growth. The later
weakly psh Definition 6.1(2), LF1891–1893, requires the opposite bound
`u <= h+O(1)`. Lemma 3.26 starts with an upper FS majorant, and the
regularization and global chart arguments use the upper convention.

Here is a concrete literal-definition test. Work over any countable
algebraically closed trivially valued characteristic-zero field and take
Y=A1, u=0. The zero function is locally psh: the constant zero is itself
tropically convex rational PL, so the constant decreasing sequence
satisfies Definition 3.8. The identity proper birational map shows that
u is weakly psh. The affine FS function max(log|z|,0) gives the upper
growth bound in Definition 6.1. Thus Theorem 6.3 applies to u under its
stated input definition.

However the lower growth condition in the literal Definition 3.15(2)
cannot hold for u=0 on A1. A list of polynomials generating k[z] must
contain a nonconstant polynomial f. At the Gauss seminorm of radius
R>1, the trivial coefficient norm gives |f|=R^deg(f). Its positive
rational coefficient c in Definition 3.15(1) makes the FS maximum at
least c deg(f) log R+C, which tends to +infinity. No such h is bounded
above by 0 plus a global constant. Therefore Theorem 6.3's literal
conclusion contradicts Definition 3.15(2) even for u=0.

The standard upper-growth convention resolves this particular issue:
u=0 is approximated by the genuinely decreasing FS sequence
max((1/j)log|z|,0). Its sole nonconstant generator z and all coefficients
and constants satisfy Definition 3.15(1). This supports identifying the
lower inequality as a convention typo. Correcting that inequality does
not independently prove all the source's other regularization or
envelope assertions. A final source-based paper should state the
convention used and justify its source application accordingly.

The exact candidate's queued independent review explicitly asks for
these growth directions and singular-value conventions to be checked.
No author correction, reviewer verdict, or original closure is inferred
from this note.
