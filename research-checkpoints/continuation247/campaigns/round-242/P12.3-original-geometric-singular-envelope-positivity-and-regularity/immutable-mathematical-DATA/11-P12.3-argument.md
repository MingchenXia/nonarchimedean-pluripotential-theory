# Partial progress on P12.3: radial envelopes on finite singular curve links

Research draft, 3 October 2026. No exact active target is claimed solved. The radial classification used below is already known in the supplied catalogue (Book Theorem 70.1.9). Its classical part is rederived from the local primary source GR25 so that the envelope calculation does not depend on accepting a catalogue description as proof. The additional results are the exact radial envelope, failure of greatest minorants, and the corresponding order projection obstruction. No priority or literature novelty claim is made for these consequences.

## Definitions and exact external inputs

K is complete and nontrivially valued. Fix pi in K with 0 < |pi| < 1, set r = |pi| and a = -log(r) > 0. Let A be a reduced strict K-affinoid algebra of pure dimension one, with a finite normalization inclusion into B = product_i K<t_i>, i = 1,...,q. Assume its analytic map nu: disjoint_union_i D_i -> U = M(A) is finite and surjective, its fiber above a K-rational point o consists of the origins p_i, and it is an isomorphism off those origins. Assume, explicitly, that the B-ideal product_i t_i^(e_i) K<t_i> lies in the conductor {b in B: bB is contained in A}, with integers e_i >= 1. These are extra hypotheses defining this partial range; they are not asserted for all excellent germs.

For a finite nonpositive profile c = (c_i), the literal radial function off o has value -(c_i/a) log|t_i| on branch i. For c_i = -infinity its entire punctured branch value is -infinity. At the radius-r Gauss point eta_i the value is c_i. A radial extension means an actual function on U with exactly these values off o; it is more restrictive than evaluating arbitrary psh functions at the eta_i.

We use classical psh in Gubler--Rabinoff, *Classically psh and pluriharmonic functions on Berkovich spaces*, arXiv:2506.13548v2, 17 September 2025. Definition 4.1 says that u: X -> R union {-infinity} is upper semicontinuous and, for every analytic extension K'/K, every K'-analytic curve Y, and every morphism f: Y -> X_(K'), the function u composed with the scalar projection and f is subharmonic in their Definition 3.4. That definition includes the identically -infinity convention.

The exact external statements used are the following, for any K-analytic space X (the complete absolute value may even be trivial in the source):

1. GR25 Proposition 4.2(2): for every f in Gamma(X,O_X), log|f| is classically psh, with log(0) = -infinity. There is no nonzerodivisor condition.
2. Proposition 4.2(3): if u_1,u_2 are classically psh and lambda_1,lambda_2 >= 0, then lambda_1 u_1 + lambda_2 u_2 and max(u_1,u_2) are classically psh. Only strictly positive scaling is used for logarithms here; constants are psh directly by the curve-test definition.
3. Proposition 4.2(4): the infimum of a decreasing NET of classically psh functions is classically psh.
4. Proposition 4.2(6): for every analytic morphism f: Y -> X, pullback of a classically psh function is classically psh; the converse holds if f is finite and surjective.
5. Theorem 6.4: a classically psh function on a K-affinoid space attains its maximum at a Shilov point.

All domains used for the maximum principle are closed discs, which are affinoid; all maps used for pullback are the given analytic normalization map or inclusions of analytic disc domains. Thus this argument needs no boundarylessness or smoothness assumption on U. It makes no CLD statement. In particular it does not infer pullback of an arbitrary Hessian current equation.

For a closed disc of radius R, its radius-R Gauss point is its unique Shilov point: for any convergent series sum b_n t^n, the triangle inequality bounds every value on the disc by max |b_n| R^n, and the Gauss seminorm attains that bound for every series. This proves directly that the singleton Gauss point is the Shilov boundary.

## Supporting lemma: classical radial classification (known result, rederived)

The exact extended radial class is C_q^ext = {0} union [-infinity,0)^q. The extension is unique, with nodal value 0 for the zero profile and -infinity otherwise. Its finite part is C_q = {0} union (-infinity,0)^q.

Proof of existence. Zero has its constant extension, and the all-minus-infinity profile has the constant minus-infinity extension. For every retained finite coordinate let lambda_i = -c_i > 0. Choose positive rationals k_(n,i)/N_n increasing to lambda_i, with a common denominator at stage n. Multiplying all numerators and this denominator by the same integer ensures k_(n,i) >= e_i without changing the rational values. In the other coordinates put the analytic function zero. The tuple (t_i^(k_(n,i))) on retained branches, zero on the others, belongs to the stated conductor ideal and hence to A. Call it f_n. GR25 Proposition 4.2(2),(3) makes g_n = (a N_n)^(-1) log|f_n| classically psh even if f_n is a zerodivisor. On retained branches g_n = (lambda_(n,i)/a) log|t_i|; on the others and at o it is minus infinity. Because |t_i| <= 1, these functions decrease to the required extension. Apply Proposition 4.2(4). A sequence is used for this explicit rational construction only; the imported closure theorem is a theorem about nets.

Proof of necessity. If c_i = 0, the points t_i = pi^m approach p_i, and their images approach o; the radial values are zero, so upper semicontinuity forces h(o) >= 0. If some c_j < 0, pull h back to branch j and restrict to its closed radius-r disc. Its unique Shilov point has value c_j < 0 (possibly minus infinity), so Theorem 6.4 forces h(o) <= c_j < 0, a contradiction. This uses actual analytic discs, not an abstract tropical fan.

Proof of uniqueness. For c = 0, the same approach to o forces h(o) >= 0, while the maximum principle on a disc forces h(o) <= 0. In the all-negative case, any finite negative coordinate c_j gives, on the radius-r^m disc, the bound h(o) <= m c_j for every m >= 1, hence h(o) = minus infinity. If all coordinates are minus infinity, the radius-r maximum principle already forces that value. All off-node values were fixed by definition.

These arguments reproduce the classical portion of Book Theorem 70.1.9. The book's additional equivalence with CLD-v2 is not imported or reproved here.

## The radial envelope theorem

Let L_q = {1,...,q}, a finite discrete branch set. Let phi be any finite real function on L_q; let h_i = min(phi_i,0). Define P_rad(phi) coordinatewise as the supremum of c <= phi over c in C_q. Then

    P_rad(phi) = h = min(phi,0).

It is an actual greatest radial minorant precisely if h is zero or every coordinate of h is strictly negative. If h has both a zero coordinate and a negative coordinate, the admissible family has no maximal element at all, and its supremum is continuous on the finite link but is outside C_q. Upper semicontinuous regularization on L_q is the identity, so it cannot restore membership.

Proof. Every admissible c is <= h. For each integer n >= 1, c^(n) = h - (1/n)(1,...,1) is strictly negative, is <= phi, and increases uniformly to h. Thus the coordinatewise supremum is h. If h lies in C_q it itself is the greatest admissible minorant. If it has both kinds of coordinates, zero is not admissible because phi has a negative coordinate. Every admissible c is therefore strictly negative on every branch. Choose epsilon > 0 smaller than min_{h_i=0}(-c_i). Put w_i = h_i where h_i < 0 and w_i = -epsilon where h_i = 0. Then w is strictly negative, w <= h <= phi, and w >= c with strict improvement on every zero coordinate of h. No c is maximal. Finiteness and discreteness of L_q imply that every finite function is continuous and equals its usc regularization.

The same supremum formula holds if one allows extended profiles in C_q^ext while keeping phi finite: the upper bound is unchanged, and the same finite approximants supply the lower bound. No general envelope theorem for arbitrary singular geometric psh cones follows.

For q = 1 there is no mixed-zero profile and this obstruction is absent. This is compatible with the known smooth curve and unibranch cusp tests; it is not a smooth-germ specialization theorem in higher dimension.

## Obstruction to an obstacle-preserving projection

For q >= 2 there is no order-preserving operator E: I_q -> C_q, where I_q = (-infinity,0]^q, such that E(phi) <= phi for every phi and E(c) = c for every c in C_q. These are the usual minimal requirements for a projection onto a minorant envelope class.

Proof. Choose a mixed-zero h in I_q, for example (-1,0) when q = 2, and put c^(n) = h - (1/n)1. Since c^(n) <= h and E fixes c^(n), monotonicity implies c^(n) <= E(h). Taking coordinatewise suprema gives h <= E(h). The minorant condition gives E(h) <= h, so E(h) = h outside its required codomain. This is a contradiction. No continuity or limit-preservation axiom was used.

There is also no continuous retraction I_q -> C_q fixing C_q, even without a minorant requirement: C_q is dense in I_q and the same sequence forces its value at h to be h. An extensive order-preserving retraction does exist: fix the zero and the strictly negative profiles and send every mixed-zero profile to zero. Thus the negative result is specifically about minorant envelopes (and, separately, continuous retractions); it is not an impossibility of every order map.

## Analytic realization on the node

Take A = K<x,y>/(xy), U = M(A), with branches D_x,D_y. This is reduced and strict, with two pure one-dimensional components. The normalization B = K<x> times K<y> consists of arbitrary pairs of series; the image of A is the pairs with equal constant terms. Indeed every series modulo xy has the form gamma + f(x) + g(y), with f(0)=g(0)=0. The idempotents (1,0),(0,1) generate B as an A-module. The conductor is x K<x> times y K<y>: multiplying by either idempotent forces a conductor element's two constant terms to vanish, and such pairs certainly multiply B into A. The normalization has the stated two origins over o and is an isomorphism off them. Thus it satisfies the explicit analytic hypotheses above with e_x=e_y=1.

The algebraic local model R = K[x,y]_(x,y)/(xy) has exactly two normalized semivaluations for the primary gauge m=(x,y), namely ord_x and ord_y, retaining their nonzero supports. To see this, v(x)+v(y)=infinity. Both cannot be infinite in the centered cone, so precisely one is finite and positive. After quotienting the infinite-support branch, every nonzero element of the one-variable local ring has form t^d times a unit; units have valuation zero because they and their inverses have nonnegative valuation. Thus every centered valuation is a positive multiple of the corresponding order, and m-normalization gives the two asserted points. They are discrete, for instance by the evaluation of x distinguishing 1 from infinity. The same direct proof applies to the formal node. Excellence is not used by the analytic or link proofs; the example is the known nodal range of the dossier, not a claimed counterexample to the entire excellent-germ programme.

Every K* is a unit in this local ring, so these local semivaluations are trivial on K. The analytic Gauss seminorms instead extend K's nontrivial absolute value. We identify their branch indices and the specified monomial profile values, not the two carriers or all their psh functions.

Now set

    g_n = log|x^n+y|/(a n).

On D_x this is log|x|/a; on D_y it is log|y|/(a n); at o it is minus infinity. Each is psh by GR25 and the sequence increases because log|y| <= 0. Its finite radius-r branch profile is (-1,-1/n), and its uniform distance on that link from (-1,0) is 1/n. Moreover x^n+y generates a primary ideal in the algebraic local model: modulo that equation and xy, x^(n+1)=y^2=0, so the radical of the ideal is m. This identifies the example with actual primary principal models, rather than just formal vectors.

The analytic pointwise supremum G is log|x|/a on D_x minus o, zero on D_y minus o, and minus infinity at o. Its usc regularization G* has the same off-node values and has value zero at o: the y-branch approaches o with value zero and all values are <= 0. It is not psh. Pulling back to the x-disc of radius r gives the value zero at the center and -1 at its unique Shilov point, contradicting Theorem 6.4. This also explains why GR25 Theorem 6.5 (an arbitrary pointwise net limit which is already usc is psh) does not apply: G is not usc, and G* is not the pointwise limit of the g_n.

The g_n are unbounded near o as functions on U. They are finite and uniformly bounded on the normalized link. Consequently this example is not a counterexample to continuity of bounded analytic Bedford--Taylor products, and no product is constructed here.

## Primary gauges and normalization

For primary ideals a,b on the node, write b_i^a = ord_i(a) and b_i^b = ord_i(b). Both are finite and strictly positive because a primary ideal contains a power of m and is proper. The corresponding point is ord_i/b_i^a. For a degree-one homogeneous ray function H, if c_i^a = H(ord_i/b_i^a), then

    c_i^b = (b_i^a / b_i^b) c_i^a.

This follows by homogeneity, and the factors telescope for three gauges, giving the exact cocycle. Positive diagonal scaling T preserves C_q, C_q^ext, mixed-zero faces, and the clipping formula: P_rad(T phi)=T P_rad(phi). Thus the envelope obstruction persists under every such gauge change. For a=m and b=(x^2,y^3), (-1,0) becomes (-1/2,0). These are changes of section of the same ray function, not an identification of all gauge-normalized values.

To compare the same literal analytic radial function, its coefficient vector at the fixed radius-r Gauss points is d_i = H(ord_i) = b_i^a c_i^a, and its branch expression is -(d_i/a)log|t_i|. Since b_i^a c_i^a = b_i^b c_i^b, this expression is unchanged by the section change. Its a-section values can also be read at the branch Gauss radii r^(1/b_i^a); those Gauss points exist even if the radii are not in |K*|. We do not assert that a gauge change keeps the numerical values at a fixed set of Gauss points equal to the section values.

On the separated normalization, each branch's radial class is [-infinity,0], so the product class is the full orthant. The normalized boundary map in this node example is a bijection of the two branch points; its fiber-constant criterion therefore imposes no restriction on profiles. Nevertheless a mixed-zero normalization tuple has node values minus infinity on the negative branch and zero on the zero branch, so it cannot descend as an actual analytic function through the two origins. This is the missing value-compatibility condition for literal radial descent. The conductor has finite value on both branch orders; its zero-dimensional quotient has no centered normalized link. Hence this phenomenon does not contradict the catalogue's conductor quotient theorem on valuation boundaries.

This also forbids any operator on all separated radial profiles which both agrees with the degree-one branchwise identity for this normalization and lands in the connected node's radial class. The known valuative degree trace is compatible with the full ideal orthant; it is not thereby a geometric radial trace. This is a diagnostic for P12.6, not a refutation of an operator defined on a smaller, genuinely compatible domain.

The radial restriction matters: the bounded function max(a^(-1) log|y| + 1,-1) is classically psh on U, has nodal value -1, and has values (-1,0) at the two radius-r Gauss points. Thus the excluded vector can be the evaluation trace of a nonradial psh function. On the subdomain |x|,|y| <= r this function is also nonpositive. A different geometric trace construction is not ruled out.

## Exact residual scope and evidence

P12.3 receives only partial progress: a fully proved envelope/no-projection calculation for the known literal radial class in the stated disc/conductor range. The underlying radial classification and the larger nodal envelope failure are known catalogue cases and are not counted as new resolutions. P12.2 still requires an independent singular geometric cone with a comparison theorem and the correct general smooth specialization. P12.4 has no bounded mixed products here; P12.5 has no energy functional or finite-energy calculus; P12.6 still requires geometric finite-map operators and conductor rules in its full scope. No complete atom is claimed, and candidate is false.

The independent exact-rational script checks/check_profiles.py exhaustively checks 340 finite-grid obstacles (dimensions 1 through 4, four obstacle values per coordinate). All assertions pass. It also checks the five displayed node profiles for n=1,2,4,16,64 and the gauge example. A finite grid DOES have a greatest negative minorant at mixed-zero obstacles; its zero coordinates equal -1/4 for the chosen grid. This is explicitly distinguished from the proved continuum supremum zero. These computations are diagnostics, not proofs of analytic psh recognition or of an infinite quantifier.
