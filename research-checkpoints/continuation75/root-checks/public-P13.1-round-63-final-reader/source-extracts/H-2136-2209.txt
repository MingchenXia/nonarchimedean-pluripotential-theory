                               6. Non-Archimedean metrics
  From now on, X will always denote a normal projective variety, unless otherwise specified,
and L will be a Q-line bundle on X.
6.1. Test configurations as non-Archimedean metrics. Motivated by Berkovich space
considerations (see §6.8 below) we introduce the following notion.
Definition 6.1. Two test configurations (X1 , L1 ), (X2 , L2 ) for (X, L) are equivalent if there
exists a test configuration (X3 , L3 ) that is a pull-back of both (X1 , L1 ) and (X2 , L2 ). An
equivalence class is called a non-Archimedean metric on L, and is denoted by φ. We denote
by φtriv the equivalence class of (XA1 , LA1 ).
   A non-Archimedean metric φ on the trivial line bundle OX can be viewed as a function
φ : X div → Q on the set of divisorial valuations on X. Indeed, by Theorem 4.6, every divisorial
valuation on X is of the form vE = b−1   E r(ordE ), where E is an irreducible component of X0
for some normal test configuration X of X. We may assume φ is represented by OX (D) for
some Q-Cartier divisor D supported on X0 , and then φ(vE ) = b−1   E ordE (D). When D = X0 ,
we get the constant function φ ≡ 1. In general, there exists C > 0 such that D ± CX0 is
effective; hence |φ| ≤ C, so φ is a bounded function. To the trivial metric on OX corresponds
the zero function.
6.2. Operations on non-Archimedean metrics. If φi is a non-Archimedean metric on
a Q-line bundle Li on X and ri ∈ Q for i = 1, 2, then we get a naturally defined non-
Archimedean metric r1 φ1 + r2 φ2 on L := r1 L1 + r2 L2 as follows: if φi is represented by a test
configuration (X , Li ) with the same X , then φ is represented by (X , r1 L1 + r2 L2 ).
   In particular, if φ, φ0 are non-Archimedean metrics on the same line bundle L, then φ−φ0 is a
non-Archimedean metric on OX , which will thus be viewed as a function on X div . If we choose
a normal representative (X , L) of φ that dominates XA1 and write as before L = ρ∗ LA1 + D

for each component E of X0 .
   If f : Y → X is a surjective morphism, with Y normal and projective, then any non-
Archimedean metric φ on L induces a non-Archimedean metric f ∗ φ on f ∗ L. Indeed, suppose
φ is represented by a test configuration (X , L). We can find a test configuration Y of Y
and a projective Gm -equivariant morphism Y → X compatible with f via the identifications
X1 ≃ X, Y1 ≃ Y . Define f ∗ φ as the metric represented by the pullback of L to Y. The
pullback of the trivial metric on L is the trivial metric on f ∗ L.
6.3. Translation and scaling. The operations above give rise to two natural actions on the
space of non-Archimedean metrics on a fixed line bundle.
   First, if φ is a non-Archimedean metric on a line bundle L, then so is φ + c, for any c ∈ Q.
Thus we obtain a translation action by (Q, +) on the set of non-Archimedean metrics.
   Second, we have a scaling action by the semigroup N∗ which to a non-Archimedean metric
φ on L associates a new non-Archimedean metric φd on L for every d ∈ N∗ . If φ is represented
by a test configuration (X , L), then φd is represented by the base change of (X , L) under the
base change t → td . This scaling action is quite useful and a particular feature of working
over a trivially valued ground field. Note that φtriv is fixed by the scaling action.

6.4. Positivity. Next we introduce positivity notions for metrics.
Definition 6.2. Assume L is ample. Then a non-Archimedean metric φ on L is called
positive if some representative (X , L) of φ is semiample.
   We denote by HNA (L) the set of all non-Archimedean positive metrics on L, i.e. the quotient
of the set of semiample test configurations by the above equivalence relation.
   We sometimes write HNA when no confusion is possible. The notation mimics H = H(L)
for the space of smooth, positively curved Hermitian metrics on L when working over C.
Lemma 6.3. When L is ample, every metric φ ∈ HNA (L) is represented by a unique normal,
ample test configuration (X , L). Every normal representative of φ is a pull-back of (X , L).
Proof. We first prove uniqueness. Let (Xi , Li ), i = 1, 2, be equivalent normal ample test
configurations, so that there exists (X3 , L3 ) as in Definition 6.1. For i = 1, 2, the birational
morphism µi : X3 → Xi satisfies (µi )∗ OX3 = OXi , by normality of Xi . It follows that (X1 , L1 )
and (X2 , L2 ) are both ample models of (X3 , L3 ), and hence (X1 , L1 ) = (X2 , L2 ) by the unique-
ness part of Proposition 2.17.
  Now pick a normal representative (X , L) of φ. By Proposition 2.17, its ample model
(Xamp , Lamp ) is a normal, ample representative, and (X , L) is a pull-back of (Xamp , Lamp ).
This proves the existence part, as well as the final assertion.                                   
