## Proposed rational PL criterion

Let X be projective over algebraically closed trivially valued k, omega an
ample rational semipositive model form, and phi a global rational model PL
function. Assume phi is locally omega-psh using the corrected supporting-
affine convex convention, not the faulty literal Definition3.1(3).

First the continuous local metric weights have positive CLD curvature.
On each compact smaller neighborhood, decreasing continuous tropical PL
approximants converge uniformly because their limit is continuous. A convex
PL function on a finite-coordinate chart is locally a finite maximum of
affine functions and has smooth convex regularized-max approximants. Near
coordinates at +infinity, a finite real PL function is locally independent
of those coordinates (source Remark3.2), so the same argument uses the
remaining finite coordinates. Consequently these approximants are locally
CLD-psh, and distributional continuity gives positive curvature for the local
limit. Changing frames adds log|unit| and preserves curvature.

Next choose a test configuration representing the total metric omega+ddc phi,
clear all rational coefficients, and extend to K=k((t)) with |t|=exp(-1).
The total metric on X_K is the actual formal-model metric, not merely its
restriction to the Gauss section. To check this, express a global model PL
function as a difference of rational multiples of flag-ideal functions.
BJ1801.08229v4 Section2.1 gives

    phi_a(v)=max_lambda(log|a_lambda|(v)+lambda),
    a=sum_lambda a_lambda t^(-lambda).

For **every** w in X_K^an, each generator t^(-lambda)f has absolute value
exp(lambda)|f(p(w))|. The ideal norm is the maximum of these values, so its
formal metric is exactly p^*phi_a. This proves the equality also at points
not on the Gauss section and avoids any erroneous claim that all of X_K^an
consists of Gauss extensions. The reference metric is transported by the same
model construction. CLD18.8.6 now gives positive curvature on all of X_K^an.

Consider an arbitrary integral curve C in the central fiber of that model.
The formal reduction map is surjective; choose an analytic point x reducing
to the generic point of C. By CLD17.7.10, C with the restricted model line
bundle is a pre-model of the residual metric at x. CLD18.8.4 for d=1 forces
the residual bundle to be numerically effective. Applying its numerical
effectiveness condition to this proper one-dimensional pre-model gives

    deg(L_model|C)>=0.

This holds for every central-fiber curve; hence the model is relatively nef.
The generic-fiber class is the retained ample rational class. By the genuine
model definition of PL intersect PSH (BJ Section3.1), phi is globally
omega-psh. This direction uses no singular envelope or finite-energy equation.
The reverse direction follows from the actual global FS/model approximation
and its local convex metric weights, so the corrected rational PL criterion
is local omega-psh iff genuine global model omega-psh.
