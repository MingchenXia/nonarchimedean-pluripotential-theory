

Lemma 2.13. Let (X , L) be a test configuration, and let (X 0 , L0 ) be a pull-back of (X , L)
such that the corresponding morphism µ : X 0 → X satisfies µ∗ OX 0 = OX . Then (X , L) and
(X 0 , L0 ) define the same filtrations on R(X, rL).
  Note that µ∗ OX 0 = OX holds automatically when X (and hence X) is normal, by Zariski’s
main theorem.
  For later use, we also record the following direct consequence of the Gm -equivariant iso-
morphism (1.2).
Lemma 2.14. Let (X , L) be a test configuration, with projection π : X → A1 . For each m
with mL a line bundle, the multiplicities of the Gm -module π∗ OX (mL)0 satisfy
                   dim (π∗ OX (mL)0 )λ = dim F λ H 0 (X, mL)/F λ+1 H 0 (X, mL)
for all λ ∈ Z. In particular, the weights of π∗ OX (mL)0 coincide with the successive minima
of F • H 0 (X, mL).
